# 算法流程

| 阶段 | 实际操作 | 主要源码 |
| --- | --- | --- |
| 1. 读取数据 | JSON → 逐帧复数 CIR、时间轴、距离轴、可选空场参考 | `io.py`、`models.py` |
| 2. 划分滑窗 | 指定 `window_sec` 和 `hop_sec`，每窗独立估计局部频率 | `pipeline.py` |
| 3. 目标门选择 | 与空场方差比较，限制 ROI，候选门计数器平滑跟踪 | `gates.py` |
| 4. 主门相位预处理 | `angle` → `unwrap` → 去趋势 → 带通 → 重叠窗口符号对齐 | `gates.py`、`signal_ops.py` |
| 5. 呼吸与拟合 | 呼吸带通提频，正余弦谐波最小二乘拟合与扣除 | `rls.py`（`use_rls=False`） |
| 6. 心跳 | 残差心跳带通 → VMD → IMF 特征 → Mamdani 模糊评分 → 心率 | `heartbeat.py`、`vmdpy.py` |
| 7. 重建与展示 | 按 Hann 窗执行 Overlap-Add，输出逐窗口频率和曲线 | `pipeline.py`、`plotting.py` |

## 需注意的实现边界

1. OLA 表示**相邻时间窗口的信号拼接重建**，不是对多个距离门进行相干叠加。
2. 模糊推理评分的三个实际输入是谱峰突出度、心跳带内能量占比与周期性。
3. 主程序将过低的复数方差、呼吸能量或心跳能量视作无效（对应频率置零）。零值不是正常生理心率。
4. 本算法读取和处理均为离线 JSON，通过部署至嵌入式系统可以使用实时传感器串流数据。

## 开发说明

项目不仅只在算法层面实现，在实际部署时候可以部署至嵌入式系统上（该算法目前已经应用于树莓派4B上）。
